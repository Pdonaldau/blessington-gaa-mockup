# Blessington GAA website concept

A concept mockup for a new Blessington GAA & LGFA website. Not the official club site.

Single-file static page (`index.html`), hosted on GitHub Pages. Club-specific settings live in the `CLUB` object at the top of the script.

Fixtures, results, news, the lotto, the Sponsors Directory, club settings and the club page text come from a Google Sheet. Until the Sheet links are set, the page shows sample data labelled "sample".

| File | What it is for |
|---|---|
| `CURRENT.md` | The present goal, the decisions in force and the next step |
| `SHEET-SETUP.md` | Steps for the club PRO to create and publish the Google Sheet |
| `sheet-template/` | `setup.gs` builds the Sheet, its checks and the phone forms. One CSV per tab, for local testing and as the starter Club and Pages rows |
| `SPONSORS-CHECK.md` | Sponsor differences against the current club site, to confirm |
| `LAUNCH.md` | What to do when the club approves launch |
